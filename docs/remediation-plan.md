# Remediation Plan

## Identify

Profile the dataset and quantify:

- category mismatches
- priority inconsistencies
- generic categories
- ownership anomalies
- missing fields

## Diagnose

Determine why quality problems occur:

- confusing taxonomy
- poor form design
- insufficient knowledge
- rushed triage
- automation gaps
- resolver reassignment
- legacy categories

## Improve

Potential actions:

- simplify category tree
- add decision guidance
- improve mandatory-field logic
- provide examples
- automate obvious classifications where safe
- coach teams using actual error patterns
- measure again after change

## Govern

Track data-quality KPIs alongside operational KPIs so poor classification does not become invisible.
